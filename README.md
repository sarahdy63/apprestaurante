# Gastro Frontend

Prototipo frontend para restaurante construido con HTML, CSS y JavaScript puro.

## Funcionalidades
- Inicio, menú, ubicación y página institucional.
- Filtros por categoría.
- Carrito persistente con `localStorage`.
- Formulario de entrega y generación de pedido demo.
- Pantalla de seguimiento del pedido.
- Acceso administrador demo.
- Gestión visual de pedidos.
- Formulario para agregar productos en la tabla del administrador.
- Diseño responsive.

## Ejecución
Abre `index.html` directamente o usa una extensión como Live Server en Visual Studio Code.

## Próxima fase con Node.js
Se recomienda implementar una API REST con Express, autenticación con JWT, base de datos PostgreSQL/MySQL y módulos para productos, categorías, pedidos, clientes y configuración del restaurante.
